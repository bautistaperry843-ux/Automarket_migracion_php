# TP1 - Sitio web estático en HTML

Versión inicial de AutoMarket desarrollada como sitio web estático con HTML y CSS.

## Contenido

- Maquetado de las páginas principales del sitio.
- Navegación entre las distintas secciones.
- Catálogo y detalle de vehículos.
- Formularios de inicio de sesión, registro, contacto y publicación.
- Secciones informativas como sobre nosotros, preguntas frecuentes y cursos.

## Tecnologías

- HTML
- CSS
- JavaScript

## Archivos principales

Los archivos de esta versión se encuentran dentro de la carpeta `.html/`:

| Archivo | Descripción |
| --- | --- |
| `index.html` | Página de inicio |
| `catalogo.html` | Catálogo de vehículos |
| `detalle de autos.html` | Detalle de vehículos |
| `registro.html` | Registro de usuario |
| `inicio de sesion.html` | Inicio de sesión |
| `vender auto.html` | Formulario de publicación |
| `contacto.html` | Formulario de contacto |
| `favoritos.html` | Vehículos favoritos |
| `sobre nosotros.html` | Información del proyecto |
| `preguntas frecuentes.html` | Preguntas frecuentes |

## Ejecución

Abrir `index.html` desde un navegador o publicar la carpeta `.html/` en un servidor web estático. La navegación y los estilos dependen de los recursos ubicados en `css/` y `js/`.

## Relación con el TP2

El trabajo siguiente migra las páginas estáticas a PHP, incorpora vistas compartidas y agrega persistencia de datos, autenticación y funciones de administración.
